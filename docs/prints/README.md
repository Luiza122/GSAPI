# Prints de execução

Esta pasta contém as evidências da API AgroOrbit rodando no Swagger.

## Prints enviados

1. `01-swagger-root.png` - teste da raiz da API retornando a página do Swagger.
2. `02-get-fazendas.png` - execução do `GET /api/fazendas` com retorno 200.
3. `03-post-fazendas.png` - execução do `POST /api/fazendas` com retorno 201.
4. `04-post-talhao.png` - execução do `POST /api/fazendas/1/talhoes` com retorno 201.
5. `05-get-equipamentos.png` - execução do `GET /api/equipamentos` com retorno 200.

Essas evidências comprovam que a API foi executada localmente, que o Swagger abriu corretamente, que o banco SQLite possui dados iniciais e que endpoints GET e POST funcionam.
